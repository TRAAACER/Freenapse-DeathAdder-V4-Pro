# Freenapse-DeathAdder V4 Pro

在原版 [freenapse](https://github.com/MatthewSaintBull/freenapse) `0.5.2` 的基础上，增加适配**炼狱蝰蛇 V4 PRO（Razer DeathAdder V4 Pro）**，并作出些许优化，由 **Gemini 4 Carbon** 和 **ChatGPT 6 Astra PRO** 共同完成修改。

后续没啥恶性 Bug 的话，不打算常规更新。

## 相比原版 0.5.2 的新增与优化

- **炼狱蝰蛇 V4 Pro 完整硬件适配**：支持有线（`1532:00BE`）与无线（`1532:00BF`）双 8000 Hz 回报率、最高 45,000 DPI、板载配置与板载宏读写，重绘右手人体工学俯视图示与底部 DPI / 电源键交互。
- **二代半球形接收器（HyperSpeed Gen-2）支持**：支持读取接收器固件版本与序列号，独立配置左 / 中 / 右 3 颗状态指示灯（电量、连接状态、回报率、DPI 档位、关闭）及 5 档亮度。
- **Focus Pro 45K 二代传感器非对称高度回读**：适配 V4 Pro 固件 `0b/85/0b` 抬起 / 着陆截断等级回读校验，配置一致时零重复写入。
- **全中文界面与实用快捷功能**：
  - 控制中心与系统托盘菜单全面中文化，修复多分类标签溢出问题（支持自动折行）；
  - 新增「桌面快捷」预设分类（支持将侧键一键设为板载 `显示桌面`、任务视图、截图、虚拟桌面切换等，关闭软件依然生效）；
  - 新增「开机静默自启」开关（登录系统直接静默驻留托盘，不弹窗）。
- **后台性能与反作弊安全优化**：
  - 前台游戏自动切方案由定时轮询改为 `SetWinEventHook` 纯事件驱动（平时零轮询唤醒，切窗 `120 ms` 响应），并完善休眠唤醒与写失败自动回滚状态机；
  - `WH_KEYBOARD_LL` 全局键盘钩子改为按需动态挂载（仅使用板载功能时零键盘钩子驻留）；
  - 新增按前台方案实时隔离软件宏与「纯板载反作弊模式」开关，默认关闭启动外网更新检查；
  - 界面与命令行默认对硬件序列号与系统用户目录脱敏。

## 使用说明

直接运行单文件 `freenapse.exe` 即可打开设置并驻留系统托盘；核心设置均直写鼠标板载内存，无需后台服务或登录账号。
